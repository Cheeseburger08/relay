# Security

Relay is an experimental personal project and has not had an independent security audit. Only operate phones/SIMs you own or have explicit permission to use.

The server terminates HTTPS/WSS and can read stored messages and live audio. Storage encryption is not end-to-end protection against the server operator. Keep the server, phone, database, and encryption/signing/push keys private and protected. Use HTTPS for remote access and unique account passwords.

Do not include credentials, personal messages, contact lists, device identifiers, or recordings in public issues. For a suspected vulnerability, use the repository's **Security → Report a vulnerability** option when available. If it is unavailable, open an issue asking for a private reporting channel without disclosing exploit details or private data.

There is no guaranteed response time or long-term security-support commitment. Maintain your own backups and test updates before depending on them.
